# PhotoFlow Studio 0.2.1

Lo Sviluppo apre anche foto che non sono nel catalogo, e il pannello delle regolazioni scorre sempre.

## Novità

- **Sviluppo di foto non importate.** «Apri file…» (**Ctrl O**) nello Sviluppo, oppure il trascinamento di
  file e cartelle da Esplora file: RAW (NEF, CR2, CR3, ARW, RAF, ORF, RW2…), DNG, JPEG, PNG e TIFF si aprono
  senza importarli. Hanno tutte le regolazioni, la riduzione del rumore, il ritaglio e l'esportazione.
  Le impostazioni si salvano nella cartella dati del programma, mai accanto all'originale, e ritornano quando
  lo stesso file si riapre. Il catalogo non cambia.

## Correzioni

- Il pannello di destra dello Sviluppo ha la barra di scorrimento sempre visibile. Prima la barra spariva e,
  mentre una foto si apriva, il pannello non scorreva: le regolazioni in fondo (rumore, avanzate, più foto)
  restavano parzialmente nascoste.

## Installazione

Scarica **`PhotoFlowStudio-0.2.1-Setup.exe`**. Chi ha già la 0.2.0 riceve l'aggiornamento dalle Impostazioni.
Nessuna migrazione del catalogo. Il programma non è firmato: se Windows mostra «Windows ha protetto il PC»,
scegli «Ulteriori informazioni» › «Esegui comunque».

## Limiti noti

- Le foto aperte dal disco non entrano in Consultazione, Revisione e ricerca: per archiviarle resta
  l'importazione.
- Se il file viene spostato o rinominato, le sue regolazioni non lo seguono.
